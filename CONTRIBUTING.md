# Contributing

Contributions that improve design quality, interoperability, accessibility, reproducibility, or honesty of reporting are welcome.

1. Open an issue describing the problem and expected behavior.
2. Make focused changes; keep `SKILL.md` self-contained and under 500 lines.
3. Preserve the canonical `skills/premium-frontend-director/SKILL.md` location and avoid copying third-party skills into this repository.
4. Run `python scripts/validate.py` and `python -m unittest discover -s tests -v`.
5. For behavior changes, document an actual Codex and/or Claude Code integration run, including skipped gates and limitations.
6. Submit a PR with reason, screenshots when applicable, and tests.

Never submit secret tokens, copyrighted assets without permission, or fabricated benchmark numbers.
