# Premium Frontend Director v1.0.0

**First public release — portable art direction and frontend implementation for coding agents.**

Premium Frontend Director is an open-source Agent Skill for bringing a coherent visual point of view to real frontend projects. It connects creative discovery, design-system decisions, implementation in the existing stack, browser inspection, and evidence-based quality gates.

## Highlights

- **One self-contained Core skill:** no mandatory companion skills, proprietary API, or special project template.
- **Three independent tool profiles:** Core, Premium, and Studio. Optional integrations extend the workflow without becoming prerequisites for Core.
- **Three creative ambition modes:** Refined, Expressive, and Immersive; independently selectable from tool profiles.
- **Five-phase workflow:** Discover → Direct → Document → Build → Prove.
- **Eleven quality gates (G1–G11):** explicit PASS / FAIL / NOT RUN reporting, including G11 for substantial visual ambition in redesigns.
- **Practical design guidance:** creative direction, reusable design documentation, accessible/responsive implementation, immersive design fallbacks, and focused review.
- **Optional visual-audit helper:** Chromium screenshots and basic browser smoke checks when Playwright and a browser are available.
- **Installation support:** documented Skills CLI flows for Codex and Claude Code, plus an alternative Claude Code plugin-marketplace route.
- **Public showcase and setup guide:** [The Art of Direction](https://the-art-of-direction.netlify.app/).

## Install Core

Open a terminal in your **target frontend project** (not this repository):

```bash
npx skills add AVL05/premium-frontend-director --skill premium-frontend-director
```

Choose your supported agent and project-local scope in the installer. Explicit variants:

```bash
# Codex
npx skills add AVL05/premium-frontend-director --skill premium-frontend-director -a codex

# Claude Code
npx skills add AVL05/premium-frontend-director --skill premium-frontend-director -a claude-code
```

The Skills CLI currently requires **Node.js 22.20+**; this is an installer requirement, not a requirement of the skill's Markdown instructions. For an alternative Claude Code marketplace installation and troubleshooting, see the [getting-started guide](../../docs/getting-started.md).

Start a new agent session and try:

```text
Use $premium-frontend-director with the Core profile and Expressive ambition.
Inspect this project, propose three genuinely different visual directions,
implement the most appropriate one in the existing stack, and review the
rendered result when browser tooling is available. Report quality gates
as PASS / FAIL / NOT RUN. Do not install companions without approval.
```

## Validation and limitations

- The [automated CI run for commit `30f88bf`](https://github.com/AVL05/premium-frontend-director/actions/runs/42387120126) passed on 2026-11-07, including Windows and Linux package/regression validation and a local Chromium browser fixture.
- Browser QA and accessibility/performance measurements require tools appropriate to the **target project**. If unavailable or not executed, they must be reported as **NOT RUN**, not PASS.
- The showcase includes its own documented visual and interaction checks; some screen-reader, system reduced-motion and performance checks were not performed.
- Reproducible per-host clean-install/discovery logs, a native Claude Code marketplace acceptance run, and independent output-quality benchmarking have not been archived. See [compatibility checks](../../docs/compatibility-testing.md).
- Optional third-party companion skills are installed and maintained separately and remain subject to their respective requirements and licenses.
