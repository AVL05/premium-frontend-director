# Creative direction playbook

## Start with an intentional premise

Build a creative brief with: audience, brand promise, conversion goal, subject matter, content inventory, technical constraints, accessibility needs, and a single-sentence visual thesis.

Create three *meaningfully different* directions, not palette swaps. For each state: typography attitude, color/material, grid and rhythm, hero treatment, imagery, one signature detail, motion behavior, mobile adaptation, trade-offs, and why the concept serves the brand.

Possible directions (examples, not mandatory): editorial minimalism; cinematic visual storytelling; tactile creative studio; precise SaaS system; brutalist typography; restrained immersive technology.

## Content before decoration

Plan each section with: question it answers, message, content source, dominant visual, desired action. Choose actual project copy/assets when possible. Never fabricate logos, customer counts, ratings, testimonials, press claims, or client work.

## Hierarchy and signature moments

- One decisive visual idea per viewport; vary scale intentionally.
- Use type systems, not a random collection of fonts. Verify font licensing.
- Tune rhythm with controlled large/small changes and comfortable reading width.
- Use imagery to communicate, not merely decorate.
- Plan 2–3 motion motifs tied to navigation, state, or narrative.
- Include a visual differentiator appropriate to the brand; don't force WebGL.

## Anti-patterns

Default blue-purple gradient, glassmorphism everywhere, nested card grids without content rationale, feature lists with repetitive icons, generic slogans, tiny low-contrast text, excessive animation, identical stock photos, and desktop layouts shrunk for mobile.

## Reference ethics

Reference mood, hierarchy, proportions, and interaction patterns. Do not clone trademarked site identity, reproduce protected illustrations, copy text, or reuse unlicensed photography. Document permitted assets.

## Creative ambition beyond conventional polish

Read `ambition-modes.md` and choose Refined, Expressive or Immersive **independently** of Core/Premium/Studio. Three concepts for Expressive or Immersive must be visibly different in staging, narrative progression and interaction—not merely palette or font. Define a first-frame composition and signature moment, using real assets. For Immersive, read `immersive-design.md` and evaluate spatial staging and optional WebGL while preserving clear fallbacks. A radical user brief must not be reduced to conservative editorial polish just because the current page is restrained.
